# ICAPACITY website preview

Russian-language design B prototype.

Live review: https://icapacity-preview.pages.dev/

## Contents

14 static HTML pages, CSS, JavaScript and local brand assets. No build step or dependencies are required. Open index.html, or serve this directory with any static web server.

## Status

- Design/content draft for review.
- Enquiry forms are disabled; no participant data is collected.
- Telegram, email delivery and CRM integrations are not connected.
- Temporary stock photography has been replaced by a decorative SVG pending licensed image selection.
- Robots directives request no indexing; they do not restrict access.
- Hosting uses Cloudflare Pages direct upload. GitHub automatic deployment is not configured.
- The existing icapacity.com.au production site is unchanged.

No credentials or participant records belong in this repository.
